# 望长盈交易系统

## 启动历史净值服务

首次使用需要安装依赖：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

启动本地服务：

```bash
.venv/bin/python server.py
```

然后打开 <http://127.0.0.1:8000/>。页面会自动加载全部基金的历史净值走势和最新公开持仓。历史净值默认缓存 6 小时，公开持仓默认缓存 24 小时；服务会在缓存过期后检查更新，网络暂时不可用时会返回最近一次成功缓存。

服务优先使用 AKShare（东方财富数据），如果东方财富域名无法解析，会自动尝试新浪财经备用源。两者都无法访问时，请先检查当前网络的 DNS 设置，再点击页面上的“重新加载”。

持仓是基金最近一个公开报告期的披露快照，并非实时仓位。页面展示数据源能够识别的前十大直接持仓。当前配置中的 ETF 联接基金会自动穿透到对应场内 ETF，展示目标 ETF 的前十大成分股，并标注目标 ETF 名称；FOF 的直接持仓可能仍需基金层级数据源支持。

如果需要立即刷新某支基金，可以请求：

```text
/api/funds/003629/history?refresh=1
```

持仓接口及强制刷新方式：

```text
/api/funds/003629/holdings
/api/funds/003629/holdings?refresh=1
```

直接双击打开 `system.html` 时，历史走势图接口无法使用；需要通过上面的本地服务访问页面。
